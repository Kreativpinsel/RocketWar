# RocketWar

A space shooter game where you control a rocket, avoid asteroids, defeat UFOs, and collect power-ups.

## Features
- Multiple rockets to unlock
- Power-up system (Shield, Wormhole)
- Upgrade system
- Mission system with daily challenges
- Local leaderboard
- Mobile support

## Controls
- UP/DOWN: Move rocket
- SPACE: Shoot
- X: Boost
- P: Pause
- F: Fullscreen
